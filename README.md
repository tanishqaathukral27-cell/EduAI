# EDUAI

An AI-powered personalized learning ecosystem that helps students plan, practice, understand, and improve.

## Hackathon MVP

- Personalized student dashboard
- AI Mentor for doubts and explanations
- Adaptive quizzes and instant feedback
- Study planner, daily goals, and streaks
- Performance analytics and recommendations

## Tech stack

React, Vite, Tailwind CSS, React Router, Framer Motion, Recharts, Lucide React, Node.js, Express, and MongoDB.

## Project structure

```text
client/  # React + Vite dashboard
server/  # Express API
```

## Local development

1. In the project folder, run `npm install`.
2. Run `npm run dev`.
3. Open the web address printed by Vite (normally `http://localhost:5173`).

The API health check is available at `http://localhost:5000/api/health`.
